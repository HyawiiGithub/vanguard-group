Vanguard Group · internal · restricted circulation

Two tiers: the admin code gives full control (add corporations, read the private inbox, rotate codes). The viewer code opens the UI read-only and cannot add anything.

What this gate actually does. A browser page cannot see the visitor's IP address, and there is no server behind GitHub Pages, so this page cannot stop anyone who is determined — codes are stored as salted PBKDF2 hashes, which hides the codes but not the fact that someone can edit the page to skip the check. Treat this as access tiering, not as security.

Rotating the viewer code really does revoke it for everyone on their next page load. It cannot close a tab someone has already unlocked — there is no server to tell them to. Use re-locking on shared machines, and rotate if a code leaks.

For genuine source-address filtering, put an edge proxy or worker in front of the site and reject requests by source address there.
